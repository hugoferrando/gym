Conseils · Prise de masse
🥩
2g de protéines / kg
Priorité absolue. Répartis sur 3-4 repas. Sources : poulet, œufs, fromage blanc, thon, whey.
⚡
Surplus calorique modéré
+200-250 kcal au-dessus de la maintenance. Trop de surplus = prise de gras inutile.
🕐
Repas post-entraînement
Dans les 2h après la séance : protéines + glucides. C'est la fenêtre anabolique principale.
💧
Hydratation
2-3L d'eau par jour minimum. Plus les jours de séance.
